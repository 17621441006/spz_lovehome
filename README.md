# 司涌脏·千寻

一个以脏脏包、小涌和小司为主角的 Three.js 森林探索游戏。当前源码对应 v21（2026-10-29）。

## 本地运行

安装 Python 3，在项目目录运行：

```bash
python restore_assets.py
python -m http.server 8642 --directory dist
```

打开 http://localhost:8642/ 。Windows 也可双击 `start.bat`，macOS / Linux 可执行 `./start.sh`。需要支持 WebGL 2 的浏览器和可用的图形加速；不要直接双击 HTML 文件。游戏运行无需 npm，模型、音效和 Three.js 都随仓库提供。

两个较大的模型（猫车、水晶）使用无损 gzip 打包在 `packed-assets/`；`restore_assets.py` 会校验并还原与线上版本逐字节相同的 GLB。启动脚本自动完成还原。直接部署 `dist/` 前也请先运行还原脚本。

## 操作

- WASD / 方向键移动，Shift 跑步，空格跳跃；手机显示触控摇杆。
- 点击画面后移动鼠标转动镜头；Esc 释放鼠标，滚轮调整距离。
- C / X 坐下，移动起身；停留约 7 秒也会自动坐下。
- E 打招呼；靠近猫车时开启乘车对话，乘车后可请求停稳下车。
- J / K 使用角色动作。脏脏包是两种踢腿，动作中再按一次可衔接下一次。
- B 打开行囊，装备折扇或切换衣服。移动时折扇合起，站定后展开。
- 主页或「换角色」选择主角，其余角色在地图中自主活动。
- 「天气」切换晴天、雨雪、昼夜；「操作说明」查看控制方式。
- 「配乐」调整音量，也能选择本地音频；本地文件不上传，刷新后需重选。
- 地址末尾加 `?q=low` 使用低画质；加 `?q=high` 使用高画质。

## v21 更新（村庄巡游与云冠秘境）

- 猫车交替运行「村庄漫游线」「星湖森林线」，覆盖 11 个站点，包括町屋、树屋、寺院、五重塔、古树桥头和星湖入口。每站停留约 6 秒；提前礼让玩家与伙伴，路清后继续行驶。按整车轮廓检查路线，弯道和坡道提前减速，乘坐镜头保持水平。
- 遮挡以相机到角色身体的 9 条有限视线检测真实三角面，至少 7 条被挡住且持续一小段时间才淡化；树后的物体、树冠空隙和少量细枝不会误触发。恢复透明度时带迟滞，避免闪烁。
- 小司改为参考图的齐肩散发与后上方小丸子，微调圆润脸型和下巴。原 GLB、UV 与骨骼保留，独立几何副本在游戏内拟合；金项链与闪光钻戒继续跟随动作。
- 小司步幅扩大、左右落脚收拢，步行周期约 0.78 秒，配合相反方向的轻摆臂；移动速度保持 v20 的 1.5333，跑步速度不变。
- 古树高度由约 44 米减至约 29.35 米。过桥是苔庭与树洞，站上光环约 0.65 秒，经短暂淡入淡出前往约 16.8 米高的环树圆台；上层光环可返回。树洞有真实开口，圆台有地板、护栏、灯与长椅。
- 白天天空改为清透蓝色与浅蓝地平线，云包含高积云、薄云带、零散小白云和蓬松积云，大小、厚薄与底部阴影不同。

验证：`npm run check`、`node scripts/village21-check.mjs`、`occlusion21-check.mjs`、`walk21-check.mjs`、`sanctuary21-check.mjs`、`main-boot-check.mjs`、`style20-check.mjs`、`human-motion-check.mjs`、`cat19-check.mjs`、`glade18-check.mjs`、`tree17-check.mjs`。主循环实际执行了进入地图、懒加载、传送往返；猫车连续模拟 700 秒，最大转向约 0.33 rad/s、常规最大加减速约 0.85 m/s²。浏览器预览环境无法建立 WebGL 上下文；实时 GPU 光照、画面与设备帧率仍需设备试玩确认。

## v19 更新（脏脏包重新绑定）

- 用用户提供的 Tripo 模型在 Blender 里重做骨骼和权重：衣服、毛发和身体共用一套平滑权重，动起来贴合在一起，不再穿模或撕裂；头部、脸、耳朵、胡须整体跟着头骨走，运行时不再修改任何网格，保留原始对称的脸。
- 新增 5 节尾巴骨、3 节马尾骨和折扇骨（合扇 = 沿扇面横向缩放）。
- 动作全部在 Blender 里重新制作：待机时身体和头部正立站好（修正原模型抬下巴的角度），配合呼吸、尾巴和马尾摆动；走路、跑步用脚部 IK 落地不滑步；坐姿改成抱膝式坐地（臀部着地、双腿前伸、尾巴绕到身侧贴地）；另有起跳、下落。
- 装备折扇时站定会举起右爪摇扇（即模型原始的执扇姿势），走动时合扇放下。
- 抬起头部露出一小段毛茸茸的脖子；脸的朝向按正面镜像对称测量后校正为正前方（`scripts/blender/face_sym.py`）。走路、跑步时双脚收到髋部正下方前后迈步，双臂与双腿反向协调摆动。
- 前踢、回旋踢直接沿用模型自带的 Tripo 动作（同一套骨骼），只去掉水平位移并叠加尾巴、马尾和头部校正。
- 脏脏包步行 1.35 米/秒、奔跑 3.2 米/秒，与动作步幅匹配。
- 删除旧的运行时补丁（`rig-repair.js`、`cat-appearance.js`、`cat-face.js`、`garment-detail.js`、`garment-shells.js`）。
- 重新生成模型：`powershell -ExecutionPolicy Bypass -File scripts\blender\pipeline.ps1 -Source <源 GLB> -Blender <blender.exe>`。

## 源码目录

- `dist/index.html`：界面与样式。
- `dist/src/main.js`：游戏循环、输入、移动和相机。
- `dist/src/modelcat.js`：脏脏包动作播放、折扇与转身倾斜。
- `scripts/blender/`：脏脏包骨骼、权重与动作的 Blender 生成脚本。
- `dist/src/human-character.js`、`characters.js`：人类角色与角色切换。
- `dist/src/terrain.js`、`dream.js`、`elder-tree.js`：地形、场景与古树秘境。
- `dist/src/catbus.js`：固定巡游、车身避障与乘降。
- `dist/src/asset-stream.js`：分阶段加载和近景细节队列。
- `dist/assets/`：游戏使用的模型、贴图、加载壁纸和音效。
- `dist/vendor/`：本地 Three.js 和加载器。
- `scripts/`：模型处理与回归检查。
- `ASSET_CREDITS.md`：素材来源和授权说明。
