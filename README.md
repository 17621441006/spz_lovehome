## 本地运行

安装 Python 3，在项目目录运行：

```bash
python restore_assets.py
python -m http.server 8642 --directory dist
```

打开 http://localhost:8642/ 。Windows 也可双击 `start.bat`，macOS / Linux 可执行 `./start.sh`。需要支持 WebGL 2 的浏览器和可用的图形加速；不要直接双击 HTML 文件。游戏运行无需 npm，模型、音效和 Three.js 都随仓库提供。

两个较大的模型（猫车、水晶）使用无损 gzip 打包在 `packed-assets/`；`restore_assets.py` 会校验并还原与线上版本逐字节相同的 GLB。启动脚本自动完成还原。直接部署 `dist/` 前也请先运行还原脚本。

## 操作

- WASD / 方向键移动，Shift 切换跑/走；双击 W 或 Shift+W 保持 2 秒后松手自动前进，W / S / 空格取消；手机显示触控摇杆。
- 点击画面后移动鼠标转动镜头；Esc 释放鼠标，滚轮调整距离。
- C / X 坐下，移动起身；停留 120 秒也会自动坐下。
- E 打招呼；靠近猫车时开启乘车对话，乘车后可请求停稳下车。
- J / K 使用角色动作。脏脏包是两种踢腿，动作中再按一次可衔接下一次。
- B 打开行囊，装备折扇或切换衣服。移动时折扇合起，站定后展开。
- 主页或「换角色」选择主角，其余角色在地图中自主活动。
- 「天气」切换晴天、雨雪、昼夜；「操作说明」查看控制方式。
- 「设置」调整配乐音量，也能选择本地音频；本地文件不上传，刷新后需重选。
- 地址末尾加 `?q=low` 使用低画质；加 `?q=high` 使用高画质。

### 海洋研究及云素材来源

参考 [Wind Waker JS](https://wind-waker-threejs.com/) 和作者的 [WebGL 源码](https://github.com/Robpayot/zelda-project-public) 的近海/远海分层、透明云平面思路。本版海洋 shader 为项目内新写实现，没有移入 Nintendo 的模型、纹理或音乐。另核对了 [three-stylized-water](https://github.com/norio/three-stylized-water)（MIT，WebGPU/TSL）和 [Three.js Water](https://threejs.org/docs/pages/Water.html)（WebGL，含额外反射渲染），考虑现有渲染器和森林负载未直接引入。

云图 `dist/assets/clouds-painted.webp`：内置 imagegen 生成，依据用户两张天空参考观察色彩与笔触，生成四种独立透明云形后调整图集布局；WebP 仅作格式压缩。提示词：四等分 2×2 透明云图集，左上高耸积云、右上宽云、左下紧凑积云、右下薄云；暖白亮面、浅蓝灰阴影、手绘水粉笔触、自然不规则轮廓，云内部实色，外围透明；不要天空、地景、人物、文字、网格和球体堆叠，各云完全位于各自单元内并留透明间隙。
